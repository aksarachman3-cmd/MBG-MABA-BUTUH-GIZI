# TASK RULE (PEDOMAN DALAM MENGERJAKAN PENUGASAN)

## ID
Setiap task memiliki ID masing-masing dengan sistem penulisan:

```text
<inisial nama>_<judul task>_<urutan task>
```

Contoh: `AR_penentuan-harga_1`

Judul task ditulis tanpa spasi. Jika lebih dari satu kata, pisahkan dengan tanda `-`.

## Pengerjaan
1. Kerjakan penugasan yang sudah ada di folder masing-masing (**JANGAN SALAH PILIH FOLDER YA**).
2. Kerjakan setiap penugasan dengan menggunakan panduan **framework git** yang telah dituliskan di [framework_git.md](framework_git.md).
3. Penamaan branch mengikuti aturan sebagai berikut:

   ```text
   <ID task>_branch
   ```

   Contoh: `AR_penentuan-harga_1_branch`

4. Utamakan dokumentasi, pastikan setiap baris kode dapat dipahami dengan baik. Tambahkan komentar yang singkat, tetapi padat dan mudah dipahami.
5. Tulis PR (Pull Request) sesuai dengan **template pull request** yang sudah dituliskan di [PR_template.md](PR_template.md).

## Bantuan
Jika ada kendala, komunikasikan langsung di group ya.
